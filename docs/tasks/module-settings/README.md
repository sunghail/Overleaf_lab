# 모듈 역할·번호·드래그 배치

- 상태: 역할·번호·세 방향 드래그 배치 구현·검증 완료.
- 범위: 기존 모듈 역할 선택, Figure와 그림 설정, 제목·캡션 번호 끄기,
  드래그 위·중간·아래 위치에 따른 앞·하위·뒤 배치.
- 원칙: 기존 본문과 식별자를 보존하고, 순환·깊이 초과·표 데이터 손실을 막는다.
- 검증: 모델 33개·화면 및 배치 7개, 실제 마우스 드래그 세 방향,
  PDF·Word 출력과 기존 생성 코드·본문 보존 확인.
- 제한: 표 역할 전환은 차단한다. 그림은 PNG/JPG를 기존 편집기에서 업로드하며
  실제 페이지 위치는 LaTeX 배치 규칙에 따른다.
