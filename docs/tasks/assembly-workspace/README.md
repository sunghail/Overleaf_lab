# 독립된 논문 조립 화면

- 상태: 독립 화면 구현·로컬 검증 완료.
- 요청: 논문 조립을 편집기 밖의 독립된 전체 화면으로 사용한다.
- 범위: 조립 목록·모듈 설정·표·템플릿·Word 출력·PDF 생성의 독립 화면.
  본문은 기존 모듈 편집기로 연결한다.
- 완료 기준: 편집기 창 없이 조립 가능, 변경 내용이 같은 원고에 저장,
  기존 편집기 패널 유지, 읽기·쓰기 권한 유지.
- 검증: 독립 사용·모듈 이동·표 저장·Word·PDF 표시·본문 연결과 파일 보존을 확인했다.
- 제한: 본문 작성은 기존 편집기를 사용한다. 다른 창의 구성 변경은 새로고침으로 불러온다.
