# 1단계 모듈 조립

- 목적: 기존 Overleaf의 편집과 PDF 컴파일을 이용한 계층형 논문 조립 기능.
- 상태: 완료. 최종 소스 이미지 재빌드와 브라우저 검증을 마쳤다.
- 작업 위치: `/Users/hail/Sideproject/03_overleaf`.
- 현재 범위: 모듈 추가, 하위 섹션, 제목 변경, 순서·부모 변경, 숨기기·복원,
  본문 편집, 조립 PDF와 재접속 후 유지.
- 완료 기준: 기능 검증과 로컬 이미지 재빌드, 브라우저 흐름 확인, GitHub 업로드.
- 원칙: 본문은 LaTeX 파일에 보존하고 숨긴 모듈을 파일 삭제로 처리하지 않는다.
- 제한: 일반 article 양식으로 검증한다. 저널별 양식, 세부 서식 설정과
  외부 수식 편집기는 다음 단계다.
- 확인: 모듈 모델 테스트 16개 통과. 브라우저에서 추가·이동·숨김·복원,
  본문 보존, PDF 번호·참조 갱신, 오래된 구조 변경과 조립 파일 직접 수정 차단 확인.
- 실행: [검증용 프로젝트](http://localhost:8080/project/6ac5fe7c6cbfab6a2eab4937)의
  왼쪽 `논문 조립` 탭. 새 프로젝트에서는 `모듈 구성 시작`을 누른다.
