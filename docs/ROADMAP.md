# 연구실 모듈형 논문 작성기 개발 단계

2026-10-07에 합의한 개발 순서다. LaTeX를 원본과 최종 출력 기반으로 유지하고,
사용자는 편집 화면에서 논문의 구성과 서식을 조작한다.

| 단계 | 범위                                                                                       | 완료 기준                                          |
| ---- | ------------------------------------------------------------------------------------------ | -------------------------------------------------- |
| 1    | 주요 모듈과 하위 섹션의 추가, 이름 변경, 순서 이동, 숨기기와 복원. 기존 편집기로 본문 작성 | 조립한 PDF 생성과 재접속 후 본문·구조 보존         |
| 2    | 대표 저널 1개와 일반 연구논문에 공식 양식·확인한 규칙 적용                                 | 초록·본문 번호·인용 방식이 선택한 양식에 맞게 출력 |
| 3    | 간격·줄간격·들여쓰기·제목 모양·페이지 넘김의 전체 및 선택 적용                             | 선택 범위에 적용되고 예외 해제 시 기본값 복원      |
| 4    | 표 테두리·정렬·열 너비·셀 병합, 그림 크기·캡션·참조 편집                                   | 화면 변경의 PDF 반영과 이동 후 번호·참조 유지      |
| 5    | LaTeX 수식 블록에 시각적 수식 편집 엔진 연결                                               | 수식 수정 후 LaTeX 저장, 미지원 문법의 원문 보존   |
| 6    | 검증된 저널·논문 유형 추가와 별도 제출 파일·원본 묶음 생성                                 | 같은 내용을 다른 저널로 전환하고 제출 파일 준비    |
| 7    | 동시 편집·구조 변경·복원 검증과 연구실 서버 운영 준비                                      | 여러 구성원 사용과 백업 복구 검증                  |

## 유지할 설계 원칙

- 논문은 주요 구성요소, 하위 섹션, 문단·표·그림·수식의 계층으로 구성한다.
- 표시 제목, 고유 식별자, 본문, 구조와 순서, 서식을 구분한다.
- 본문 LaTeX를 보존하고 구조를 바꿀 때 본문을 다시 작성하지 않는다.
- 서식은 저널 기본값, 논문 전체 설정, 개별 모듈·문단 설정으로 관리한다.
- 전체 기본값 변경과 선택 범위의 예외까지 통일하는 동작을 구분한다.
- 들여쓰기와 모듈의 상하위 관계는 별개다.
- 저널 규칙은 저널, 논문 유형, 제출 단계와 확인한 출처·버전을 포함한다.
- 수식 편집 엔진은 입력을 담당하며 최종 논문 출력은 LaTeX가 담당한다.

현재 작업 상태와 검증은 [1단계 기록](tasks/module-assembly/README.md)을 참고한다.
첫 버전의 조작 방법은 [논문 조립 사용법](MODULE_ASSEMBLY.md)에 있다.
저널 규칙의 근거는 [가이드 조사 기록](tasks/journal-guides/README.md)에 있다.
