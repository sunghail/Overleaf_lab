# 논문 조립 첫 버전 사용법

1. [로컬 Overleaf](http://localhost:8080)에 로그인하고 프로젝트를 연다.
2. 왼쪽 세로 도구 모음의 **논문 조립** 탭에서 **모듈 구성 시작**을 누른다.
3. Abstract, Introduction, Methods와 하위 섹션, Results, Conclusion이 생성된다.
   모듈을 선택하고 기존 Visual 또는 Code 편집기로 본문을 작성한다.
4. **모듈 추가**에서 종류와 넣을 위치를 선택한다. 일반 섹션은 다른 모듈
   안에 넣을 수 있다. 초록과 Highlights는 논문 최상위에 넣는다.
5. 제목은 **변경**, 순서는 위·아래 버튼이나 드래그로 바꾼다.
   드래그 대상의 위쪽 25%는 앞에, 가운데 50%는 하위에, 아래쪽 25%는 뒤에 놓인다.
   안내선과 **위에 넣기·하위에 넣기·아래에 넣기** 표시로 위치를 확인한다.
   부모를 바꾸려면 **상위 모듈 → 이동**을 사용한다.
   목록에는 조립 PDF의 제목 규칙에 따라 `1`, `2.1`, `2.1.1` 같은 번호를
   표시한다. 이동·숨기기·복원 시 목록 번호는 바로 갱신되며 PDF는 Recompile
   후 갱신된다. 초록·Highlights와 숨긴 모듈에는 제목 번호를 붙이지 않는다.
6. **숨기기**는 해당 모듈과 자식들을 PDF에서 제외한다. 본문 파일은 보관한다.
   **숨긴 모듈도 보기**를 켜고 숨긴 부모를 선택해 **복원**하면 다시 포함된다.
7. 기존 **Recompile** 버튼으로 PDF를 갱신한다. 원본 다운로드에는 구성 파일과
   숨긴 본문을 포함한 LaTeX 파일들이 들어간다.

## 조립 전용 전체 화면

논문 조립 탭 위의 **조립 전용 화면 열기**를 누르면 별도 페이지가 열린다.
편집기 창을 닫아도 조립 목록·모듈 설정·표·템플릿·Word 출력을 사용할 수 있다.
왼쪽의 모듈을 선택하면 오른쪽에서 제목·순서·포함 여부를 바꾼다.
본문은 **이 모듈 본문 편집**으로 해당 문서의 기존 편집기를 연다.
표 모듈을 선택하면 표 입력 도구가 열린다.

**PDF 만들기**는 저장된 내용으로 PDF를 생성한다. 본문을 편집했다면 저장을 마친 뒤 누른다.
전용 미리보기의 이전·다음 페이지로 이동하고 **PDF 다운로드**로 파일을 받을 수 있다.
다른 창에서 구성 변경을 했다면 전용 화면의 **새로고침**으로 최신 구성을 불러온다.
저장 시 버전이 다르면 기존 구성 변경 보호 기능이 충돌을 알리고 최신 구성을 불러온다.
여기서 템플릿으로 만든 새 원고도 전용 조립 화면에서 이어서 사용한다.

직접 주소는 `/project/<프로젝트 ID>/lab-assembly/workspace`다.
별도 데스크톱 설치 앱이나 항상 위에 표시되는 바탕화면 위젯은 이번 범위에 포함하지 않는다.
작업 상태는 [독립 화면 작업 기록](tasks/assembly-workspace/README.md)에 있다.

## 저장과 편집

모듈을 선택하면 **모듈 역할**에서 섹션·번호 없는 구성·초록·Highlights·Figure를
선택하고 **역할 적용**으로 변경할 수 있다. 본문 파일과 식별자는 보존한다.
표는 전용 셀 데이터를 보호하기 위해 다른 역할로 전환하지 않으며 새 표로 추가한다.

**제목 번호 표시**를 끄면 해당 섹션과 하위 섹션의 번호가 사라진다.
다음 번호 있는 섹션은 빈 번호 없이 이어진다. 하위 섹션에서 번호 표시를 켜도
번호 없는 부모의 설정을 따른다. 표·그림은 독립된 캡션 순서를 사용하며
**캡션 번호 표시**로 각각 끌 수 있다. **숨기기**는 본문까지 제외하는 별도 설정이다.

Figure는 **그림 파일**에서 프로젝트의 PNG·JPG를 선택하고 너비(10–100%)를 정한다.
파일 업로드는 기존 편집기를 사용하며 업로드 후 조립 화면을 새로고침한다.
모듈 제목이 캡션이다. LaTeX의 표준 그림 배치 규칙에 따라 실제 페이지 위치가 조정될 수 있다.

표·그림은 하위 모듈을 가질 수 없다. 초록·Highlights는 최상위에 둔다.
드래그 시 자기 자신·자손 아래·3단계를 넘는 위치는 **넣을 수 없는 위치**로 표시한다.
사용법과 검증 범위는 [모듈 설정 기록](tasks/module-settings/README.md)에 있다.

기존 문서는 그대로 보관하고 새 조립 문서를 main으로 지정한다. 기존 문서의
내용을 새 모듈로 자동 분할하지는 않는다. 필요한 내용을 모듈 본문으로 옮긴다.

본문은 `lab-module-<UUID>.tex`, 구조는 `lab-assembly.json`, 자동 생성된 조립
문서는 `lab-assembled.tex`에 저장된다. 본문은 모듈 선택 후 편집하고, 구조는
논문 조립 탭에서 변경한다. 파일 이름을 직접 바꾸거나 삭제하면 연결이 끊어진다.

`조립 LaTeX 보기`에서 생성 코드를 확인할 수 있다. 이 파일을 직접 수정하면
다음 구조 변경이 차단된다. 수정본을 별도 파일에 보관한 뒤 파일 이력에서
원래 생성 파일을 복원하고 다시 시도한다. 다른 화면에서 구조가 바뀌었다면
최신 구성을 불러온 뒤 다시 변경한다.

수식은 Code 편집기에서 LaTeX로 작성한다. 제목과 번호는 조립기가 생성하므로
일반적인 본문 파일에는 `\documentclass`, `\begin{document}`나 모듈 제목용
`\section`을 다시 넣을 필요가 없다. 섹션 참조에는 생성 문서의
`\label{lab:<UUID>}`를 사용하면 위치 이동 후에도 같은 대상을 참조한다.

## 이번 버전의 범위

- 일반 `article` 및 Word 기반 Cleaner Production 01, 최대 100개 모듈, 3단계 제목 구조를 지원한다.
- 일반 섹션은 번호 있는 제목, 초록은 article의 Abstract 환경,
  Highlights의 하위 모듈은 글머리표로 출력된다.
- 초록의 모듈 이름은 목록 표시용이며 PDF 제목은 article의 Abstract다.
- Word 원고를 기준으로 한 Cleaner Production 01과 개인 템플릿 재사용·표 편집은
  [템플릿 사용법](CLEANER_TEMPLATE.md)에 있다. 공식 LaTeX 저널 프로필,
  사용자 지정 간격·들여쓰기와 시각적 수식 편집은 [개발 단계](ROADMAP.md)에 따라 추가한다.
- 연구실 공개 운영 전 다중 사용자 검증과 백업·복원 검증은 7단계에서 진행한다.
